# Currículum Web – Proyecto Front-End

Proyecto de desarrollo Front-End que consiste en la creación de un currículum web responsivo, utilizando **HTML5** y **Bootstrap 5**.  
El sitio presenta información profesional organizada de forma clara, aplicando buenas prácticas de estructura semántica y diseño *mobile-git pushfirst*.  
Incluye secciones de experiencia, formación, habilidades y un formulario de contacto preparado para validación.

## Tecnologías utilizadas

- HTML5  
- Bootstrap 5  
- CSS (clases utilitarias de Bootstrap)  
- JavaScript (validaciones básicas, en etapas posteriores)

## Características principales

- Diseño responsive (mobile-first)  
- Uso correcto de etiquetas semánticas (`header`, `main`, `section`, `footer`)  
- Navegación simple y clara  
- Organización del contenido mediante grilla Bootstrap  
- Formulario de contacto estructurado y listo para validación  
- Estética minimalista y profesional
